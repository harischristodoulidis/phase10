# Phase 10

A pass-and-play web version of the **Phase 10** card game for 2–6 players on one device.

Built with React 19, TypeScript, Redux Toolkit, React Router and Tailwind CSS v4 on the [Vite+](https://viteplus.dev) toolchain.

## Getting started

```bash
vp install     # install dependencies
vp dev         # start the dev server
vp check       # format, lint, type check
vp test        # run tests
vp run build   # production build
```
